# Визуализатор графа зависимостей (Вариант 30)

## 1. Общее описание

Консольная утилита на Go для построения и визуализации графа зависимостей пакетов Rust (Cargo). Программа написана только на стандартной библиотеке Go без использования cargo и сторонних библиотек.

Функции программы:
- чтение настроек из файла config.toml и их проверка;
- загрузка метаданных пакетов из индекса crates.io и извлечение прямых зависимостей;
- построение транзитивного графа зависимостей рекурсивным обходом в ширину (BFS) с ограничением глубины и обработкой циклов;
- поиск обратных зависимостей (пакетов, которые зависят от указанного);
- сохранение графа в файл формата SVG (через Graphviz DOT) и вывод ASCII-дерева в консоль.

## 2. Настройки и основные функции

Параметры в config.toml:
- package_name - имя корневого пакета, для которого строится граф (строка).
- repo_url - адрес индекса Cargo или путь к локальному тестовому файлу (строка).
- test_mode - режим работы с локальным файлом вместо сети (true или false).
- output_file - имя итогового SVG-файла с графом (строка).
- ascii_tree - выводить ли дерево зависимостей в консоль (true или false).
- max_depth - максимальная глубина обхода графа (целое число от 1 и выше).

Флаги запуска:
- -config - путь к файлу конфигурации (по умолчанию config.toml).
- -reverse - имя пакета для поиска обратных зависимостей (по умолчанию берется package_name).

Файлы в папке src/:
- config/config.go - парсер TOML-файла и валидация параметров.
- cargo/fetcher.go - HTTP-запросы к индексу Cargo и разбор JSON с зависимостями.
- graph/builder.go - построение графа рекурсивным BFS и чтение тестовых файлов.
- graph/reverse.go - инверсия графа и поиск обратных зависимостей.
- visual/render.go - генерация описания для Graphviz (DOT), сохранение SVG и сборка ASCII-дерева.

## 3. Сборка и запуск тестов

Сборка проекта:
go build -o project2 ./src

Запуск приложения:
go run ./src -config config.toml

Запуск тестов:
go test -v ./tests/...

## 4. Примеры использования и сравнение с cargo tree

Тестовый режим (test_mode = true):
Проверка работы на графе с циклами проводилась на локальном файле test_repo.txt. Программа корректно обрабатывает циклические зависимости, строит дерево и находит обратные зависимости.

Проверка на реальных пакетах и сравнение с cargo tree (test_mode = false):
Тестирование и визуализация графа в SVG проводились на трех пакетах из индекса crates.io: thiserror, serde и log.

Причины расхождений результатов со штатным cargo tree:
- Опциональные зависимости (features): программа берет из индекса все обычные (normal) зависимости, включая опциональные, а cargo tree по умолчанию строит дерево только для default features.
- Целевая платформа (target): в индексе Cargo записаны зависимости под все ОС, а cargo tree оставляет только те, что нужны для текущей операционной системы.
- Разрешение версий и Cargo.lock: cargo tree опирается на конкретный файл Cargo.lock, а утилита анализирует последнюю опубликованную версию каждого пакета из индекса.
