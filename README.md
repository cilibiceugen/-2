# Визуализатор графа зависимостей (Вариант №30)

## 1. Общее описание
CLI-утилита на языке Go для анализа и визуализации графа зависимостей пакетов формата Rust (Cargo) без использования сторонних менеджеров пакетов и библиотек получения зависимостей.

## 2. Описание всех функций и настроек
Приложение настраивается через файл конфигурации формата TOML (по умолчанию `config.toml`):
* `package_name` (string) — имя анализируемого пакета.
* `repo_url` (string) — URL-адрес репозитория (индекса пакетов) или путь к файлу тестового репозитория.
* `test_mode` (bool) — режим работы с тестовым репозиторием (`true` или `false`).
* `output_file` (string) — имя выходного файла с изображением графа (например, `graph.svg`).
* `ascii_tree` (bool) — режим вывода зависимостей в формате ASCII-дерева (`true` или `false`).
* `max_depth` (int) — максимальная глубина анализа зависимостей (положительное целое число).

## 3. Команды для сборки проекта и запуска тестов
* Сборка проекта: `make build`
* Запуск приложения: `make run`
* Запуск тестов: `make test`
* Очистка артефактов: `make clean`

## 4. Примеры использования
Запуск с указанием пути к конфигурационному файлу:
```bash
cd src && go run . -config ../config.toml
```
